# Андрей — мессенджер (PWA)
Вход/регистрация по номеру телефона и паролю, поиск по номеру, личные чаты, группы, истории (24 ч), аудио- и видеозвонки (WebRTC), сквозное шифрование. Работает в браузере на ПК, iOS и Android; ставится на рабочий стол как приложение.

## Установка (Ubuntu 24.04, всё на одном сервере)
    sudo ./install.sh                         # только IP (определится сам) — без домена
    sudo ./install.sh 203.0.113.5             # только IP, указанный явно
    sudo ./install.sh messenger.example.com you@mail.com   # с доменом, Let's Encrypt
Один Node.js-процесс отдаёт сайт, HTTPS и WebSocket; на той же машине ставится coturn (TURN) для звонков. Порты: 80, 443, 3478 (tcp/udp), 49160–49200 (udp).
Локально: `npm install && npm start` → http://localhost:3000

### Режим «только IP»
Публичного сертификата для голого IP нет, поэтому скрипт создаёт свой центр сертификации. Камера, микрофон и установка на экран работают только по HTTPS, значит, на каждом устройстве один раз нужно доверить сертификат: откройте `http://IP/ca.crt`.
- **Android:** Настройки → Безопасность → Шифрование и учётные данные → Установить сертификат → Сертификат ЦС.
- **iOS:** скачайте в Safari → Настройки → «Профиль загружен» → Установить; затем Основные → Об этом устройстве → Доверие сертификатам → включить.
- **ПК:** Chrome/Edge — «Дополнительно → Перейти на сайт» либо импорт ca.crt в «Доверенные корневые центры».
Срок сертификата сервера — 800 дней; для продления запустите install.sh ещё раз (данные сохраняются, CA прежний).

## На рабочий стол
Android/Chrome — кнопка «Установить» или меню → «Установить приложение». iOS/Safari — «Поделиться» → «На экран Домой». ПК/Chrome/Edge — значок установки в адресной строке.

## Возможности
Чаты и группы (добавление участников, выход), истории 24 ч, фото, файлы до 4 МБ, голосовые сообщения, удаление своих сообщений у всех, счётчики непрочитанных и уведомления, аудио/видеозвонки с отключением микрофона и камеры, выход из аккаунта, лимиты попыток входа и регистрации.

## Шифрование
- У каждого устройства своя пара ECDH P‑256; приватный ключ неизвлекаемый и хранится в IndexedDB, на сервер уходит только публичный.
- Каждое сообщение/история/сигнал звонка шифруется случайным ключом AES‑256‑GCM, который заворачивается отдельно для каждого получателя (ECDH+AES‑GCM). Сервер хранит только шифртекст.
- Звонки: медиа защищено DTLS‑SRTP, а SDP/ICE передаются в зашифрованном виде.
- Пароли — scrypt с солью. Трафик — TLS (nginx + Let's Encrypt).

## Ограничения
- Ключ привязан к устройству: на новом устройстве старые сообщения не прочитать. Потеря данных браузера = потеря истории.
- Нет проверки отпечатков ключей: теоретически сервер мог бы подменить публичный ключ (MITM) при первом контакте.
- Нет forward secrecy (статические ключи), в отличие от Signal.
- TURN работает на публичном IP сервера; за NAT потребуется `external-ip` в /etc/turnserver.conf.
- Доступ к контактам (Contact Picker) есть только в Android Chrome; галерея выбирается системным диалогом. Микрофон/камеру запрашиваем один раз, но запоминание зависит от браузера (в Safari iOS может спрашивать повторно).
